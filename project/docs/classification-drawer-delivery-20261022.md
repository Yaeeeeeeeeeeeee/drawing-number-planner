# 图号归类、H10与详情抽屉修正版交付

已验证应用源码：`4adbc053a2ad86b67a4917ad0bd468b1907b247a`。

## 修改

1. 图号库提供“自动归类”，直接保存唯一产品候选，支持从关联PDF的完整SKU-型号目录补足旧识别字段。保存前备份、事务写绑定/审计、保存后统计及列表刷新；已有确定归属不覆盖，多产品歧义保留待处理。归类后即使详情刷新失败也更新目录数量，详情错误单独显示。
2. H10实际目录“03.量产后的变更明细/00.首批大货”现在与“变更文件”同样识别批次和转曲类型。重扫保留已有索引ID和原始文件，不要求清库。
3. 图号详情改为基础信息、文件信息、业务关联、状态与操作四板块。双列六项基础信息；文件52px横排、省略名、固定单行打开位置、标题单次存在状态、无路径及空白卡片；业务关联仅最早可靠批次和首次实际纳入BOM。
4. 保留改变产品所属功能，无独立外观或关联维护板块。使用中/历史版本均可发起释放资格检查；未正式使用的reserved保留明确启用入口，不假装已使用。
5. 释放仅限可证明未使用、无受保护引用的正式reserved。历史扫描、已启用、旧作废无法证明从未使用、PDF/BOM/外发/图号关系及删除前证据均阻止释放。产品退出前也检查资格并保存全部占号记录的引用证据，包括此前已保留删除的记录，防止清历史后误释放。

## 安装及首次运行

- 关闭旧版图号规划器，保留原数据目录及planner.db，可先自行复制备份。
- 解压下载的安装ZIP，运行中文安装程序，可自定义新安装目录；不要覆盖或清空业务数据目录。
- 首次启动选择原planner.db所在数据目录；本轮无新Schema，旧版仍走既有备份/兼容升级流程。
- 图号库点击“自动归类”，查看实际更新数量和目录结果；若归错，在查看/管理详情中点“改变产品所属”，选择正确产品、填写原因保存。
- PDF文件中心保留原根目录并“扫描资料库”一次，补齐此前H10漏识别的批次。无需删除索引、重建产品或重命名PDF。
- 程序启动不自动归并产品、不释放图号、不清除历史，也不携带示例业务数据库。
