# 图号规划器 v1.1.1

修复扫描漏识别、列宽撑出窗口，并调整每次安装后的数据库选择。沿用 Schema22，无新增数据库迁移。

- PDF：兼容现有生产变更目录的括号说明及历史“变更明细”名称，扫描/批次/列表使用同一范围规则。源文件仍显示在“未转曲源文件”，转曲文件按真实批次显示。未扫描的范围外旧索引不再误报为本次删除/缺失；重扫同一路径保留原索引身份和业务引用。
- 表格：总宽度跟随容器，拖动列边界重新分配内部宽度；窗口缩放保留偏好比例，旧超宽缓存自动拟合。保留换序、记忆、恢复默认和冻结表头。操作不再被挤出窗口；最小宽度确实无法容纳时保留必要横滚。
- 数据库：每次成功安装或同版本重装后首次启动，询问使用旧库或创建新库。新库自动创建在独立目录，无需选择文件；普通重启使用上次选择。取消、损坏文件或初始化失败保留旧配置与原库；选择前执行只读SQLite校验。

关闭旧程序并完整备份数据目录后安装。继续使用现有业务时选择原 planner.db，不要误选创建新库。新库不覆盖原库，也不携带示例业务数据。

本版不修改原始 PDF、图号编码或历史占号，不重写 BOM/外发快照，不自动归并产品。

详见 [安装升级说明](install-and-upgrade.md) 与 [根因、修改及验证记录](hotfix-1.1.1-20261027.md)。真实用户数据库及物理DPI未在开发环境；验收使用隔离旧库和真实临时文件。
