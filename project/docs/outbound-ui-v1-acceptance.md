## 场景

1. 本次变更：所选批次三项资料。
2. 当前完整：六项，后三项展示历史沿用及来源批次。
3. 异常：缺失、冲突、待确认独立表达，文件可用维度单独展示；异常禁止选择，整份预览存在异常即阻塞生成。
4. 分包：复用现有纯分包函数，模拟三份 ZIP，名称、大小、数量、路径及位置操作齐全；不写 ZIP，不选择目录，不定位真实文件。
5. 单文件超限：51MB 样例由现有纯分包函数拒绝，保留 50MB 上限。
6. 邮件：原联系人、签名、模板与手工编辑替换确认流程；字段附近复制按钮与复制反馈。
7. 历史：默认折叠，主表展开分包和文件事实/修改明细快照；存取均复制，当前输入和返回对象不能改写快照。
