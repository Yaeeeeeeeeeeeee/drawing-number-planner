# 图号规划器 v1.2.0 · 邮件模板导入与外发草稿

- 迁移检查增加 XLSX 邮件模板识别和可编辑预览，支持首批/更新工作表、厂家横向合并栏、多场景、多段正文；其他场景只展示，不误导入。重复模板明确新增/跳过/更新，预览后数据变化会阻止过期覆盖；导入前备份，事务保存联系人与模板。
- 邮件配置取消日常必填内部编码，具体字段错误明确提示；变量按需插入，模板保存不依赖产品上下文或签名，签名独立组合。
- ZIP 成功后直接生成邮件草稿，从实际成功选入 ZIP 的冻结清单填充。仅变化的铭牌不会连同未变化说明书一起写成变更；不可靠比较须核对确认。
- 按厂家/资料类型/场景选择模板，可调整收件人/抄送；逐项编辑、排序、合并或删除变更说明，切换文件名展示。正文同步并保护手工编辑，支持复制主题、正文和整封内容，不自动发送邮件。
- 修复导入弹窗受页面动画影响的滚动/关闭，以及页面切换后晚到表格尺寸回调。

Schema 仍为22，无新增数据库迁移；保留旧图号占用、BOM、PDF、二维码和外发快照，不修改原始文件，不携带示例业务数据库。原有中文、自选安装路径、每次安装询问旧库/新库及卸载保留数据行为继续有效。

使用方法：[安装与升级](install-and-upgrade.md)。实现和验收：[V5.1 交付记录](v51-mail-delivery-20261027.md)。
