# 全局 UI 一致性修正

用户已批准实施；连续完成五步，不逐阶段请求确认。规范依据：docs/design-audit-three-skills-20261023.md 与本轮批准的五步方案。

现有非 master 开发分支继续增量修改，保留已有审查文档改动；不另建会丢失未提交审查证据的工作树。无 Schema/占号/历史数据变更。

1. 基础：整理控件两档规格、隐藏规则、图标与对比度；审查 CSS 优先级，移除明确过时的抽屉样式。
2. 图号：去重复名称、透明内层、单行文件、工具栏和危险操作间距；保留四板块及释放资格校验。
3. PDF：单一空列表状态，中性批量工具栏，列宽预算及常用操作可见。
4. 全模块：QR手动文件弹窗焦点/Tab/Escape/inert/恢复，保留取消不保存和处理中保护；统一九模块控件与空态图标。
5. 验证：相关及全量自动化、类型与构建；浏览器截图（空库只读，原有有数据验证夹具不入安装包）；独立末次代码审查；提交开发分支、Windows安装/旧库升级检查、中文自选路径安装工件。

共享接口：基础控件须保护 checkbox/radio、图标按钮、文本动作、原生文件选择；PDF空表格不销毁已有数据加载场景；QR模态不能因busy切换重建焦点或允许保存中取消。

行为回归先观察失败再修复；纯颜色/间距不添加镜像样式测试，以真实浏览器布局和人工截图复核验证。用户真实库及物理DPI未提供，不能据夹具宣称已验收真实数据。
