## 不能以样例替代的事实

- 真实数量、产品名称、历史状态、文件可用性及预检结论来自现有接口，不复制截图样例值。
- 字典没有独立引用预检契约：仅准确说明两类可能影响，由原删除服务最终核对。
- 外发不返回每份 ZIP 文件数量；多份时显示“未提供”，总数独立显示。不能把总数分摊或当成每份数量。
- 外发冲突/待确认记录不一定已验证物理文件；无法确定时显示“待核实”，不能冒充可用。
- 规划品牌/尺寸编码用原字典只读查询补充；该可选元信息查询失败不会阻塞原规划基础查询或猜造编码。
- QR 样例图片只用于真实索引、文件存在与关联 UI 验收，不代表新增二维码解码能力；未确认文件仍待确认。
