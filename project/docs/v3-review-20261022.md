# V3 独立审查结果

只读审查工作差异与隔离测试；不操作用户真实数据库。

发现并修复：

1. 外发比较基准在当前批次缺序号时先按日期，选前一批时又按序号，可能选错基准。现沿用同一排序依据，真实 SQLite/PDF 回归证明旧调用失败、新调用通过。
2. 历史产品候选确认在外层事务内才调用内部备份，备份被跳过。现提前备份，并禁止不能保证该时机的嵌套磁盘调用；回归检查备份中的旧归属、绑定及审计。
3. 关联前后计数仅统计持久化绑定，与已可查询的可靠关联不一致。现共享有效产品 SQL，另列已确认绑定数；不把补写审计误报为新恢复归属。
4. QR 查询切换未复位滚动，屏幕外已关闭详情留有测量高度。现查询键复位，主行/详情独立测量并按当前展开状态使用。

复审：V3关联、产品服务、虚拟表、缓存、v18迁移共5文件40测试通过，差异空白检查通过。未发现未解决关键或重要安全问题。完整构建、全套测试和Windows真实运行由交付验证另记。
