## 视觉基准（设计建议，实施时按真实可读性校准）

- 内容 #FFFFFF，导航 #F5F5F5，次级面板 #F7F7F7，分隔线 #E5E5E5，正文 #252525，主按钮深灰近黑。文字规范优先于参考色板中的 #E8E8E8，不以图片面积比例作为精确参数。
- 页面标题22–24px，模块标题15–16px，表格正文13px，表头12–13px，辅助信息12px。中文适配 Segoe UI / Microsoft YaHei UI / Microsoft YaHei；图号等标识符用可读等宽字体并提供回退。
- 顶部栏52–56px，主导航190–220px，产品导航180–220px，详情默认300–360px；内容边距16–24px，控件间距8–12px。
- 普通单行表格40–44px，长文件名、异常和多字段BOM允许增高。卡片圆角8–10px，控件6–8px，图标16–18px，1px浅灰边线，以横向分隔为主。
- 哑光白灰，无大面积蓝色、渐变、玻璃拟态和厚重卡片；无阴影或极轻阴影。导航100–150ms，详情150–200ms，尊重减少动态效果设置。
- 悬停、选中、键盘焦点、加载、成功和失败清晰。来源、业务状态、占号、文件存在、匹配和批次使用分别映射真实字段，不合并为单一“正常”状态。

## 按 CSS 可用宽度布局

宽度和高度均使用实际内容视口测量；不依据显示器物理分辨率决定断点。下表为已确认方案的初始调校值，不是不可调整的业务常量。

| CSS宽度 | 初始模式 |
|---|---|
| <720 | 非本轮完整工作流最低支持范围，不能标为通过 |
| 720–959 | 主导航抽屉、产品导航折叠／面板、详情抽屉；主列表优先 |
| 960–1279 | 主导航可收起，产品导航默认收起，图号详情默认抽屉 |
| 1280–1599 | 预算足够才固定展开详情；产品导航默认收起 |
| 1600–1919 | 按模块及表格预算允许辅助栏同时展开 |
| ≥1920 | 完整多区工作台，增加有效字段与可见行数，不整体放大 |

起始预算：主导航200px、产品导航200px、详情340px，完整图号主表暂按约800px评估。用最长真实图号、状态组合和列宽校准；窄窗可将次级字段转详情、允许表格内部滚动，但完整图号可查看复制，关键状态仍可到达。先收产品导航，再将详情转抽屉，仍不足则收主导航；预算约束优先于断点。

720×600下确认按钮、错误提示、完整图号和弹窗必须可操作；内容可独立滚动，禁止整页横向溢出。高度不足时面板／弹窗内部滚动，不能被固定页头或底栏遮挡。自动折叠保留记录、筛选、勾选与编辑输入，不改变业务授权、不自动选第一条，不新增写请求。

4K保留文字和控件基准，扩展列表信息量；编辑表单和危险确认仍限宽。禁止全局 CSS zoom 强行适配。

| 规划 | 保留产品／外观、派生条、行旁预计图号、底部查重占号和真实已保存结果；输入改变撤销旧预览，保留approvedInput／expectedFullCode，预计不冒充正式保存。 |
| 产品 | 七列、三属性、三列QR、限宽退出工作表；保留查询、编辑、启停、历史确认、精确QR跳转、完整预检及两次确认；预检数量不冒充常规关系统计。 |
| BOM | 连续工作表和已有添加／查询入口；改善编辑与参考原值层级，不改变字段顺序、独立附件角色、沿用、原记录编辑、并发锁、历史快照和引用保护；不恢复Vn业务标签、不推断字段Diff。 |
| PDF | 复用真实产品／批次接口和筛选、文件详情字段及桌面定位；待关联／待确认／未归批次仍有入口，不用当前页数量冒充产品总数；保留扫描、路径查看复制、缺失索引与全局索引维护的不同确认。无PDF预览／下载空壳。 |
| QR | 平铺元信息、文件工作表、完整文件名下路径入口；用途、启用、文件存在、扫描匹配／人工确认独立；保留编辑、关联、缺失禁用、真实图片及桌面操作、删除保护。扫描匹配不等于解码。 |
| 外发 | 连续准备／结果／邮件、四项选择、八列和真实分包；保留目录授权、preview token、歧义BOM选择、ZIP写入、人工草稿、联系人／模板及不可变历史；未知每包数量“未提供”，未知物理可用性“待核实”，不新增发送邮件。 |
| 字典／批次 | 字典五类、父子浏览、编码锁定、名称编辑引线、等高保存取消、操作语义色及真实删除恢复；批次保留现有入口、业务标签和原路径，不新增未经实现的重命名／删除等功能。不强制三栏。 |
| 迁移／恢复 | 问题优先、真实原因、候选及筛选外选择数量；全选范围仍是全部可导入候选。恢复保留左下入口和实际返回值，不将取消受理称终态，不因视觉验收执行恢复命令。 |

产品到BOM／文件的上下文导航不在首轮新增；不得恢复暂停的APP式往返或伪造阻塞记录定位。参考图仅视觉依据，不引入样例数据、假容量、下载、全局搜索、多标签、创建人或新业务版本。
