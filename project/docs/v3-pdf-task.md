# V3 PDF 文件中心实施与复核

日期：2026-10-22。范围：文件查询、批次顺序、共享产品批次导航、PDF 页面及对应隔离测试。未打开或修改用户真实业务库、原始 PDF、758 条本地图号数据；真实批次重复原因和实际修复数量不能由夹具代替。

## 已确认的问题与修复

- 旧导航把独立外观版本作为节点，包含无文件的“初始外观”；同一物理批次还能按版本映射出现在不同分支。现在按类别→产品→实际批次显示，旧版本表、引用和兼容查询仍保留；无意义版本空节点与外观状态入口不再显示。
- 同名批次不等于重复数据：显示 helper 去掉 `00.` 等前缀，人工显示名也可相同；不同实际目录、不同批次 ID 必须保留。`diagnostics()` 返回 ID、原路径、原名、显示名、同名 ID 与规范路径重复项。隔离回归确认两个真实路径可显示同名，但没有规范路径重复，不能自动合并或删除。用户库未提供，因此没有声称定位用户库中每个疑似重复项的真实原因。
- 文件查询原先直接采用历史记录 `product_id`，该字段可能来自目录匹配，不能视作确认。文件列表和导航统计现在共用 `effectiveDrawingProductSql`，复用图号的完整记录身份、已确认绑定和可靠业务证据。产品仅在目录被识别或刚创建时，仍保持待关联；明确历史候选确认或人工绑定后，无须重扫即显示正确产品。没有新增第二套关系数据。
- 列表和统计共用 `FILE_SEARCH_JOINS` 与 `fileSearchPredicate`。统计在一个只读快照中计算；包括产品、类别、批次、待关联和存在状态，测试逐个比较导航数量与真实列表查询数量，包括 10,001 条文件索引，统计不受列表页大小限制。
- 当前批次按完整可靠业务序号优先、完整有效业务日期次之，在品牌/尺寸/原字典外观码范围内计算；同产品不同外观码可分别有当前批次。日期/序号缺失、并列和混合编码批次不伪造当前状态；不根据 PDF 修改时间选择。颜色不另建外观代际。
- 批次只显示“当前批次”“历史批次”，不确定时不附加“使用未确定”“外观待确认”。改名仅保留左侧图标，右侧文件行重复入口删除；修改显示名与版本号，不改原目录、PDF 路径、文件名或外发快照。
- 默认显示紧凑目录/总数/未匹配数/扫描工具栏，根目录保存和扫描统计、变化明细折叠保留。最终复核发现原候选工具栏把待关联产品数当作所需统计；以红测复现后改用独立、缓存的未匹配文件聚合，待关联产品树计数不变。
- 文件表固定每次 100 条增量读取，虚拟渲染，有独立查询标识和过期响应丢弃；移除页码、每页条数、上下页。增量加载保留已选项和表头 DOM；切换查询回到顶部，迟到的旧查询页不会追加到新范围。文件名/批次/SKU/型号保持单行，操作居中。

## 安全与兼容证据

`file-repository` / `pdf-management` 回归覆盖：历史图号稳定索引禁止清除、清除不释放占号、BOM 和外发快照及外键保持、暂不纳入和内容变化复核状态重扫保持、可清除无业务引用 PDF 时保留批次和扫描轨迹。改名回归比较完整文件索引行及原批次路径/原名，确认只有显示元数据改变，并拒绝过期 revision。生产数据不执行自动修复。

历史测试夹具中需要确认产品的情形改为显式绑定或历史候选确认；目录识别夹具仍保留未确认断言，没有以恢复目录自动关联来满足旧断言。

## 用户本机检查

展开普通产品确认直接显示真实批次，没有“初始外观”空层；不同外观码最新有效批次可各自显示当前。悬停同名批次改名图标核对实际路径，只有确认同一规范路径/同一 ID 的重复呈现才属于重复问题。左侧改名后核对磁盘目录和 PDF 名未变。滚动超过 100 条、勾选后继续滚动并返回；快速切换产品/待关联范围核对没有混入旧结果。对于已人工确认的完整图号，核对 PDF 与图号库归属一致；只有目录推测者继续待关联。
