# 图号规划器 Phase 4 设计

日期：2026-08-25  
状态：依据已批准 V1.0 总设计进入实施

## 1. 阶段目标

Phase 4 增加本地资料根目录设置、集中路径解析与目录策略、PDF 递归扫描、图号匹配和转曲前后识别。PDF 本体始终保存在用户选择的本地资料库中，应用只建立索引，不读取或写入 PDF 内容。

本阶段不实现文件复制、批量重命名、撤销、旧型号参考复制、外发打包、外发历史、服务器 API、自动上传或同步。

## 2. 存储边界

- 资料根目录是本机设置，保存到应用数据目录的 `settings.json`，不写入 SQLite。
- `settings.json` 只保存用户明确配置的资料根目录；代码中没有默认盘符、用户名或电脑绝对路径。
- SQLite 新增 `pdf_files` 表。业务路径字段只保存相对于资料根目录的路径，不允许盘符、UNC 前缀或 `..`。
- 图号、BOM 与 PDF 的关系以数据库外键为准，不依赖 PDF 所处文件夹层级。
- 资料根目录迁移后只修改本机设置，再重新扫描；不修改图号、BOM 或 PDF 相对路径记录。

`pdf_files` 保存：相对路径、实际文件名、可空图号关联、匹配状态、转曲类型、文件大小、最后修改时间、最近扫描时间和当前是否存在。相对路径唯一。

匹配状态：

- `matched`：文件名只包含一个已知完整图号；
- `unmatched`：文件名不包含已知完整图号；
- `conflict`：文件名包含多个不同的已知完整图号。

转曲类型：文件名包含完整中文标记 `（转曲）` 时为 `outlined`，否则为 `source`。扩展名匹配不区分大小写。

## 3. 路径与目录策略

集中路径模块负责：

1. 校验资料根目录是已存在的绝对目录；
2. 将资料根目录规范化为真实路径；
3. 将相对路径解析为绝对路径，并拒绝绝对路径、盘符、UNC、空字节和 `..`；
4. 检查解析结果和真实文件路径仍位于资料根目录内；
5. 把扫描得到的文件转换为规范相对路径。

扫描器不跟随符号链接或目录联接。遇到单个无法读取的目录或文件时，扫描整体失败且不更新数据库，避免把一次不完整扫描误认为文件缺失。

目录策略单独放在一个模块中，提供默认 `{品牌}\{产品类别}\{型号}` 目录计算和 Windows 非法字符清理。Phase 4 只定义和测试该策略，不提前创建目录，也不让扫描匹配依赖该结构。

## 4. 扫描与数据库更新

扫描流程：

1. 读取并验证当前资料根目录；
2. 递归枚举普通 PDF 文件，跳过符号链接和目录联接；
3. 一次读取当前数据库中的全部完整图号；
4. 仅依据文件名识别唯一图号和转曲类型；
5. 文件系统扫描全部成功后，在一个 SQLite 事务中更新索引；
6. 本次看到的记录标记为存在，未看到的旧记录标记为缺失，不硬删除。

同一进程内不允许两个扫描同时执行。扫描失败不改变上一次成功扫描的索引状态。

## 5. 本机接口

- `GET /api/files/settings`：读取资料根目录设置及可用状态。
- `PUT /api/files/settings`：验证并保存资料根目录。写操作需要现有本机会话令牌。
- `POST /api/files/scan`：扫描当前资料根目录并返回总数、匹配、未匹配、冲突和缺失统计。
- `GET /api/files`：按文件名/相对路径关键词、匹配状态、转曲类型和存在状态组合筛选。

请求格式错误返回 400；未配置根目录、目录不可用、路径越界或扫描失败返回稳定业务错误；并发扫描返回 409。接口不接受任意待扫描绝对路径，所有扫描只能针对已保存的资料根目录。

## 6. PDF 文件中心

启用左侧“PDF 文件中心”，页面包含：

- 资料根目录输入、保存按钮和当前可用状态；
- “扫描资料库”按钮及最近一次结果；
- 匹配状态、转曲类型、存在状态和关键词筛选；
- PDF 列表：文件名、相对路径、匹配图号、转曲前后、大小、修改时间、状态；
- 空目录、未配置、扫描中、失败和无结果状态。

Phase 4 不提供假重命名、假复制或假外发按钮。设置采用明确的路径文本输入，保持桌面窗口和浏览器预览共用同一页面与 API，不为文件夹选择器增加新的 Electron IPC 架构。

## 7. 安全与故障处理

- 文件扫描只读，不打开、修改或删除 PDF。
- 路径安全在核心服务集中执行，路由和页面不自行拼接绝对路径。
- 本机设置使用临时文件加原子替换写入，避免中途退出留下半份 JSON。
- 设置新根目录成功后不立即改写 PDF 索引；用户点击扫描后才更新存在状态。
- 数据库迁移为版本 4 的加法迁移，升级前沿用现有强制备份与事务回滚。

## 8. 测试与验收

- 路径测试覆盖安全相对路径、`..`、绝对路径、盘符、UNC 和符号链接逃逸。
- 设置测试覆盖未配置、有效目录、无效目录和原子保存。
- 匹配测试覆盖唯一图号、无图号、多个图号、大小写 PDF 扩展名和 `（转曲）`。
- 扫描测试使用真实临时目录和 SQLite，验证新增、更新、缺失标记、失败不写库及相对路径存储。
- API 测试覆盖设置、扫描、筛选、错误码和本机写令牌。
- 界面测试覆盖保存根目录、触发扫描、统计与筛选结果。
- 端到端测试使用临时资料根目录和真实 PDF 占位文件，验证同一图号的普通 PDF 与 `（转曲）` PDF 被识别为转曲前后，且数据库不含资料根目录绝对路径。
- 阶段结束运行全部测试、类型检查、生产构建、数据库迁移、桌面启动和浏览器流程，并保留桌面窗口供用户预览。
