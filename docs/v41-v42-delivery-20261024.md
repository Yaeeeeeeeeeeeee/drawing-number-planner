# V4.1 / V4.2 与 v1.0.0 交付记录

## 变更与根因

图号库原“版本”列只读取 `item.version`，当前正式/历史查询没有提供这一独立字段，因而大多显示“未记录”；它不是 BOM 版本，也不代表颜色。本次仅移除该列表占位，保留历史版本及相关兼容数据。新颜色使用现有完整编码和字典：第三段前两位是外观码、后一位是颜色码，分别精确映射；不根据文件名或型号猜颜色。主类别按编码键稳定映射低饱和配色，其他键使用稳定散列色板，不修改字典。类别、斜杠及项目同排，缩窄时项目省略。

正式图号存在沿用关系时，服务层和 Schema17 的 `drawing_usage_planned_update` 触发器均阻止停用；Schema20仅解除正常启停限制，保留完整编码、身份、归属及删除保护。历史专用 API 原已具备双向状态能力，未发现所谓历史 ID 必然丢失的证据。本次统一列表/详情/筛选为“使用中 / 已停用”，并覆盖正式与历史双向恢复。内部 reserved 仍保留未正式启用含义，不能据列表标签放宽释放资格。

PDF 主文件区原来只允许 `effectiveCurrentFileIds`，将不在当前业务批次的实际存在实例排到历史区域，误报主区缺失；历史图号查询还遗漏了同完整编码但挂在正式记录上的旧索引。现按明确完整图号关系对称读取具体实例，传回批次ID，以实际索引存在事实与业务归属分开判断。唯一存在实例可靠展示；多个实例只有唯一可信关系或明确所选范围才展示，不任意取最新，不重复铺历史卡片。显式选择缺失批次不会偷偷回退到另批次。索引状态来自扫描，磁盘外部变化应重扫；打开位置沿用既有实际路径/文件校验。

后端隔离查询证据与迁移说明见 [V4.1 后端验证](v41-backend-verification-20261024.md)：修正前历史详情 source `[]`、outlined `[3,4]`；修正后 source `[1]`、outlined `[2,3,4]`，缺失 ID4 仍缺失，索引和原文件字节未改。同号的多个批次实例保留独立身份。

## PDF 与共享交互

批次菜单在 `ProductCatalogNavigation.tsx` 的 portal 实现，鼠标附近夹紧视口；外部点击/Esc关闭，右键不导航，移除常驻铅笔。重命名复用 `MaterialBatchService.rename` 的显示名/修订检查，不改目录或快照。

项目原先没有独立的安全批次删除入口。本次在现有 MaterialBatchService/Repository 增加预检与事务删除：只有空且无引用的内部批次可删除；全部实际外键、PDF索引、人工归纳、BOM、外发快照及归并前后历史均受保护。归并快照只将 `references[{table:'material_batches',ids:[…]}]` 当作批次引用，不把同值产品或图号ID误判。返回真实阻止原因，预检指纹变化时重查，不拆关联、不删磁盘目录或PDF。左侧选中批次删除后清除该批次范围，保留兼容筛选；计数和列表同步。

FilesPage 的六按钮采用同一行两组：左“全选 / 取消选择 / 人工归纳”，右“排除所选文件 / 恢复所选文件 / 移除文件记录”。原预览/确认/受保护索引 API 和已加载选择范围保持不变。旧全局30px主题曾覆盖局部34px，浏览器实际测量复现后修正变量及窄屏覆盖；两宽度均34px且仅工具栏内部横滚。

共享 LayoutTable/DataTable 增加缺失的可见恢复默认布局入口、表头抓手和列边调宽标记，保留原本机宽度/顺序保存和键盘交互；PDF/图号既有顶部入口不重复。虚拟滚动扣除表头与caption高度。旧版本列的本机布局迁移到颜色列，不修改业务库。

## Windows 安装

原脚本没有禁止桌面路径；默认目录浏览缺少桌面快捷入口。本次改用 Windows Shell 文件夹选择器，保留真实子目录路径，桌面根统一到独立 DrawingNumberPlanner 子目录，交互及静默规则一致，旧示例目标仍拒绝且不删除。用户机器的原始具体错误未获得本地重现，不将它伪称为已查明的权限错误。

实际 Windows 构建为 Inno6.7.1，采用现代IFileDialog。验收先后修正旧SHBrowseForFolder消息、UIA把真实Edit标成Pane、英文系统Yes按钮等验证差异；均根据保存的窗口证据，保留真实点击、路径读回和Ready断言。Windows40000750812已通过桌面浏览/中文子目录/根归一、全文件哈希、已有EXE和数据库哨兵、从桌面目录启动、旧v15→20、备份/WAL/回滚、原生QR及旧V4交互。新增验收首次停在同名表头/筛选框定位，已限定真实控件类型/区域，最终清理版仍须完整重跑，不能以首轮部分通过冒充最终成功。
