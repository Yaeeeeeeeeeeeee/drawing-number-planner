# 图号规划器 v1.5.0 · 包材模板与制图任务交互优化

「制图任务」独立放在图号规划下方。「包材模板」保留 AIT 模板管理、模板匹配规则、项目生成设置三个页签，尺寸配置改为无需尺寸、二维、三维的中文选项；旧参数、规格、规则和映射保留。上传的 AIT 可读取命名文字对象与字体，也可手动配置。生成仅替换完整图号，沿用原有 Illustrator 副本和可编辑 PDF 导出流程。

图号规划移除制图尺寸，保留逐行实时预览、明确查重与事务占号。成功卡片支持复制和精确定位图号库；生成文件直接带入已保存产品和图号，在制图任务内配置制作参数。返回页面时刷新基础资料并保留编辑内容和占号结果。

任务自动命名、自动选择唯一可靠产品目录，以紧凑项目行展示文件状态并按需展开设置。新任务直接使用产品 `00.临时文件`，旧任务继续使用原嵌套目录，不自动迁移文件。归档只清理实际归档且已核验的受管文件，不删除00、旧目录或其他文件。

任务记录可二次确认删除；未完成任务须明确确认后果，忙碌或部分归档任务需先恢复。删除保留物理AIT/PDF、历史数据、图号占用、BOM和外发引用，并安全解除任务锁。旧任务保留文件不会自动被新任务认领。

PDF文件中心新增快捷类型/缺失筛选，以及列表批次、修改日期筛选。筛选不改产品目录归属，也不缩小正式扫描的02/03目录及批次范围。扫描失败不报为实际删除。

升级至 Schema25，保留旧表及历史引用。安装前关闭程序、完整备份数据目录，首次启动选择原 `planner.db`；保留原本地资料路径。上一版程序不能直接打开已升级的库，回退需要升级前备份。安装包不携带用户业务数据库或真实设计文件。

**开发和CI没有授权安装的Illustrator及真实AIT。已核验对象替换与导出协议、JSX合约、真实人工PDF保存/归档流程；实际字体、设计版式及PDF重开可编辑性尚需本机验证，不作为已通过项目。**

使用方式和兼容说明见[安装升级说明](install-and-upgrade.md)及[本轮修改与验证记录](packaging-ui-delivery-20261102.md)。
