# 图号规划器 v1.4.0 · 包材模板与制图任务

新增「数据来源 → 包材模板」：维护 AIT 原件、字段映射、独立尺寸规格、默认规格、比例锁、尺寸范围规则及项目生成方式。复用现有产品、品牌和项目 ID，不从 BOM 读取尺寸。

图号确认占号后可创建制图任务；每个真实产品同时一个未完成任务。支持 AIT 自动生成、人工 PDF 和无需生成项目，逐项失败重试、人工文件监听及待关联处理。任务、尺寸、匹配及文件状态持久保存，重启可继续。

归档前逐项检查并确认当前 PDF 的 SHA256。新文件排他归档到 `02.未转曲源文件`；正式文件修改先复制到任务目录，确认后校验原件未变化、备份并安全替换。归档只扫描涉及产品；索引验证成功后清理本任务未变化的受管文件。未知文件、其他任务、根 `00.临时文件`、备份及任务历史保留。

Windows 本机通过 PowerShell STA / Illustrator COM / JSX 使用模板副本，检查命名对象、必填值、声明字体和链接资源，启用 `Preserve Illustrator Editing Capabilities` 导出 PDF，不生成独立 AI。超时保留操作证据，避免重复导出；不关闭用户已有文档。

**真实 Adobe 验收范围：开发及 CI 没有授权安装的 Illustrator，也没有用户实际 AIT。自动化协议与 JSX 合约测试不等于真实 AIT、字体、版式或 PDF 重开可编辑验收。这些项目尚需在本地完成。** 先上传实际模板、按对象名配置映射和字体，再运行「本机检查」，用一份文件生成并在 Illustrator 重新打开核对后批量使用。测试 AIT 仅为匿名上传合约文件，不是可交付设计模板。

升级到 Schema24，新增模板/尺寸/规则/项目配置、制图任务/项目/待关联文件/归档日志及扫描范围元数据。保留旧业务表和历史引用，不更改图号编码、占号、BOM、二维码或外发快照，不自动归并产品，不改变当前资料根目录。迁移前备份并校验，失败回滚。

安装前关闭旧程序并完整备份已选数据目录；安装后选择原 `planner.db` 继续业务。1.3.1 及更早版本不能直接打开已升级到 Schema24 的库，回退必须使用升级前的独立备份。安装/卸载均不删除业务资料。

详见 [包材模板使用与验证](ait-packaging-delivery-20261030.md)及[安装升级说明](install-and-upgrade.md)。
