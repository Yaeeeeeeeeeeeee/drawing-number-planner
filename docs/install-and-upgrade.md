# 安装、升级与恢复

## 安装

1. 从 v1.0.0 Release 下载 `DrawingNumberPlanner-1.0.0-Windows-x64-Setup.exe`，可对照同页 `SHA256SUMS.txt` 核验。
2. 关闭正在运行的旧版。中文安装向导中选择安装路径；“浏览”可选择桌面、中文子文件夹及 Windows 已重定向的桌面位置。直接选桌面根时使用其中独立的 `DrawingNumberPlanner` 子目录。
3. 首次启动，已有用户选择原数据目录内的 `planner.db`，新用户明确创建空数据库。不要通过创建空库解决旧库兼容问题。
4. 核对本地资料根目录及外发输出目录。安装程序目录、数据目录和资料目录彼此独立。

稳定配置位于 `%APPDATA%\DrawingNumberPlanner\profile.json`，只保存数据目录选择；业务数据及 `settings.json` 保留在已选目录。通过应用安全恢复入口可以重新选择数据目录。安装和卸载均不清除业务目录。

## 升级

升级前关闭程序，完整备份数据目录，包括 `planner.db`、存在时的 WAL/SHM、`settings.json`、`backups` 和托管附件；原始资料及外发文件另按原位置保留。不要只复制仍在写入中的单一数据库文件。

新版读取并升级原库。Schema19→20 仅修正正式图号状态更新触发器，使受保护的沿用关系不阻止正常启停；编码、产品归属、删除和占号保护仍在。更早的数据库依次执行原有兼容迁移。迁移先生成并校验备份，在事务内检查历史行、外键和 schema 对象；备份失败或迁移失败时不继续启动业务。

升级不会自动执行 ZC100 或其他真实产品归并，不自动清理 PDF 或释放图号。需要纠正归属时使用图号库既有关联诊断/改变产品所属、PDF 人工归纳；存在歧义时核对真实产品 ID 和文件。归并由用户在本地独立确认。

## 恢复

迁移失败会回滚，先保留错误信息和原目录，勿反复新建空库。若需恢复备份：关闭程序，另外保存失败后的完整目录；在独立目录恢复迁移前已校验的备份及对应设置/附件，再通过安全恢复入口选择该 `planner.db`。

上一版回退包仅支持 Schema19 或更早数据库，不能直接打开升级后的 Schema20。回退程序必须配套使用升级前备份；保留新版数据库，避免丢失升级后新增的业务。回退代码 Tag 不代替数据库备份。
