# 已确认需求正式实施授权（2026-11-05）

来源：用户本会话《正式实施授权与自主发布指令》，覆盖此前计划的冲突部分。基线 v1.5.0 / Schema25。

## 授权及边界

允许范围内代码、必要迁移、测试、提交、标签、既有 Windows 构建和正式发布，不分阶段等待批准。生产数据库如实际可访问，操作前独立备份并验证，迁移后完整性及关键数据核对；不得清空重建、批量删历史、擅自释放图号、删除或覆盖真实设计/附件。测试仅隔离库和临时文件。不自动安装到用户电脑。没有访问到生产数据库不得报告已修复生产数据。

## P0

明确“保留文件并结束任务”：图号删除、PDF脱钩、等待索引均不能永久阻断结束。结束不依赖重关联，不认领强制脱钩旧PDF，不伪装归档完成。停止安全后释放产品任务锁并留痕；停止失败保留任务和锁。保留Schema25唯一性、隔离触发器、任务历史、PDF/AIT/AI/BOM/索引和归档日志。G-03预检过期在同一弹窗重查，重新核对新令牌；同一错误不刷屏。

## P1

四步：产品资料→选择项目→图号检查→确认占号。两模式：新建（单产品多项目）、批量（多产品独立项目）；搜索启用型号，以真实产品ID区分，切换保选择；停用/缺资料禁止正式占号并指出原因。型号分组检查默认展开；单项重查、完整确认、成功/异常独立结果、复制及精确图号库定位。右侧编码拆解/检查预览可拖宽。

沿用完整编码前缀及流水号规则，不增加未经确认的分配规则。不同项目实际发生完整编码冲突时阻止并说明，不以改流水规则掩盖编码冲突。

每型号每项目默认其他颜色共用白色；白色基准必须来自该产品真实存在的白色记录，无真实记录则项目异常，不能虚构、跨型号共用或重复占号。取消共用则独立占号；已有正式图号和BOM不修改。

两模式独立持久草稿在当前数据目录原子写入，纳入自动备份，重启恢复步骤/产品/项目/输入；恢复一律重新检查。删除草稿不释放号码；不建占号批次编号或档案。

## P2

- G-02 每次返回任务页刷新历史，保搜索/筛选/滚动/展开/详情/未保存编辑；旧响应不覆盖新数据，无高频无意义轮询。
- G-05 指定模板/规则、任务历史、规划首载、PDF元数据、QR辅助资料区分加载、空库、无搜索结果、部分失败、完全失败、重试；保留旧有效数据和输入，不吞错成空数组。
- G-01 所有启用产品监听实际02/03，不以00/任务为前提，保扫描范围和隔离。
- G-06 扫描当前型号、当前类别、全库，类别范围精确。
- G-09 列表为最近扫描状态，详情实时观察；两种时点有区分，不为列表刷新扫全盘。
- G-08 >500条自动分批，总体进度、分批结果、失败可重试，不重复成功操作；服务端安全校验保留。
- G-11 正式重新选择数据库/数据目录入口；检查版本、完整性、兼容性，保护当前库，不合并、不对不兼容库初始化，保自动备份；不是完整恢复中心。
