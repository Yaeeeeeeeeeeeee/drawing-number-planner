# P4 截图反馈修正

本轮基于0bda9c5的实际验收反馈；原图号/BOM/PDF/二维码/外发关系和数据保持。用户要求复制成功不显示字样，表格居中、状态有色底框、导航层级明确、安全恢复收窄、图号标题区紧凑、二维码产品表取消数量列。

## 根因及调整

- 复制成功反馈原在普通div内以p参与排版。浏览器复现：复制后首行52px变为94px，图标与图号中心错开22.5px。删除成功文本，控件用行内span；失败反馈绝对定位并保留可访问提示，不撑高表格。完整图号仍写入剪贴板，复制不打开详情。
- 图号库和产品档案表头、正文统一居中。资料独立状态仍来自原二维码业务记录，已启用绿框、已停用红框、未配置灰框；按钮保留原精确产品/用途导航，不以文件存在推断状态。
- “其他／待关联批次”更名为“未关联产品的批次（N）”，仅有真实条目时展示。批次节点按批次ID导航，与另一个“图号查询”分组中的“未关联图号”并列，后者原查询仍是缺少产品或明确BOM/已完成外发使用批次的图号。正常已占号但尚未使用的图号也会命中，不代表图号异常或文件缺失。过滤语义和SQL不变。
- PDF导航复用同组件，另设“文件查询→待确认文件”。原“未关联／未归批次核对”实际上打开全库，取消这个误导/重复入口；“全部文件”完整重置产品/批次/关键词等筛选并包含未关联数据，不声称提供了后端没有的精确null关联筛选。
- 图号范围标题改为18px；产品模式主标题显示型号，副行显示SKU和全部资料批次。搜索条件顺序为关键词、主类别、状态、检索、更多筛选。面板分隔条改为连续浅灰细线，保留键盘/鼠标调宽。
- 安全恢复浮层最大360px，小窗口保留16px边距，内部高度受窗口约束；只改CSS，不调用或改变恢复操作。
- 二维码管理主表移除“二维码用途/3项”汇总列。展开子表的全部用途、业务/文件/匹配状态和原管理操作保留。

## 验证边界

仅浏览器接口夹具与原有Windows隔离样例自动验收，不修改真实数据库，不新建样例记录制造密度，不执行恢复命令。截图标明夹具，不能当作用户业务数据。Windows物理4K/DPI/跨屏仍需本机核对。前次16项既有全量失败未因本次UI修正关闭；本次只跑相关回归及构建/界面核对。

测试、截图和Windows新包结果将在本轮实际返回后记录。
