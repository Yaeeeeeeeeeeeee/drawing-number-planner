# PDF 管理及产品目录修正（2026-10-23）

## 本轮修正

- PDF 管理预览、执行和批次重命名请求补齐 JSON Content-Type。原客户端把 JSON 字符串作为纯文本发送，服务端因此报“PDF 管理预览参数无效”；保留服务端参数校验和引用保护。
- 图号库在归类、关联修改及重新进入页面后刷新产品、批次与使用关系。字典加载失败不再阻断产品目录；各来源独立处理失败，保留上次成功目录并提供重试。过期请求不能覆盖新目录。
- PDF 与图号导航不再用筛选后的数量判断批次归属。PDF 接口增加只读、不过滤的 batchProducts 映射；图号复用既有使用关系。筛选结果为 0 时，原产品和批次层级保持，数量显示真实的 0。
- 返回图号库时刷新上次已提交查询，保留尚未提交的筛选输入，不意外执行草稿条件。

本轮不新增 Schema 迁移，不写产品归属，不更改占号、BOM、二维码和外发历史规则，不操作用户真实数据库或磁盘 PDF。

## 按钮用途

- 清除已选索引：仅移除可安全清除的索引；被图号或历史引用保护的记录保留，显示阻止原因。原始 PDF 不删除，后续扫描可重新发现。
- 暂不纳入已选：保存排除决定，正常管理列表不显示；未变化的文件重扫后仍排除。
- 恢复纳入已选：先把“纳入范围”切为“暂不纳入”，选择文件后恢复。

## 验证与交付

新增真实 HTTP 客户端测试通过 23 个本地 PDF 的预览、暂不纳入、重扫、恢复、清除及再扫描，逐步核对文件字节未变。批次改名核对 ID、路径和原名称保持。

目录测试覆盖过滤为零、真实数据库只读快照、关联后 0 条新增时仍刷新目录、字典单项失败、切页刷新、过期响应和未提交条件。Windows 安装版还将实际点击三种管理操作并核对原文件哈希。

最终全量158文件1354测试通过（171.36秒），TypeScript、Vite与Main构建通过；独立审查发现的切页草稿执行问题已修复。Windows工件编号在实际安装版验证后补录，当前不宣称Windows通过。

## 安装与本地核对

1. 退出旧程序，备份当前完整数据目录。
2. 解压最终中文安装包，运行 EXE，可自选程序安装路径。
3. 启动继续选择原业务数据库，无需清空数据库、重建图号或重新关联已确认记录。
4. 打开图号库，核对原关联产品出现在目录；输入筛选并查询，核对批次仍在原产品下。
5. PDF 操作先使用不重要的纯扫描索引检查预览。涉及历史引用的记录仍受保护。

用户真实长目录、物理显示器 DPI 和本地业务库未在云端验收。安装包不含测试业务数据。
