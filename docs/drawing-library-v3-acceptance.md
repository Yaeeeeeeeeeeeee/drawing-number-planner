# 图号库第三版收口（开发 Mock 预览）

## 范围

仅图号库 renderer、局部 CSS 与对应测试。不改 Schema、migration、正式 API/查询、业务生命周期、确认流程或其他页面。不合并 master。

Mock 使用开发构建 + `?mock=drawing-library` 双重开关，默认关闭。数据仅为 renderer 内存样例。Mock API 不复制、不读取、不委托真实 API；白名单外的方法默认拒绝。维护、批量删除、恢复、关联和磁盘定位在 Mock 下禁用。正式运行继续使用原 API。

## 验收证据

- 首先观察真实写 API 泄漏回归失败，再确认隔离修正后通过。
- 全量 Vitest：88 文件、809 项通过。
- Typecheck、浏览器生产构建、桌面编译通过。
- 关键判断文字：文件完整性、资料使用、状态均为 12 CSS px；普通行约 44px，默认 20 条。
- 浏览器实测 table viewport：1080 下 767/767，1200 下 925/925，1280 下 967/967（clientWidth/scrollWidth）。状态列直接可见，不隐藏字段。
- 整页 clientWidth/scrollWidth 相同；1080 下长图号可增加至三行，但不缩小文字。
- Enter 可展开；关闭按钮/Escape 可关闭，并返回原图号按钮焦点。展开状态和详情 ID 通过 aria-expanded/aria-controls 关联。
- 高级筛选独立四列等宽网格；初次第三版验收中宽屏详情两列、1080 单列（下方详情最终收口更新了此断点）；维护/文件/关联/危险区分组。
- 正常/回收站隔离及状态/文件存在筛选仅在 Mock 做最小修正，未修改正式查询。
