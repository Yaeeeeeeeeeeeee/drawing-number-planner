# P4 产品用途列、规划编号、BOM明细及复制图标反馈（2026-10-16）

用户明确要求取消产品表的“关联资料”大标题，改为三个项目：说明书、售后卡、菜谱。

## 实施

- `ProductsPage.tsx`将原单个关联资料单元格拆为上述顺序的三列，不重复列名作为单元格文字。
- 每列只取当前产品及准确用途key对应的既有二维码，显示实际已启用/已停用状态，并保留按记录ID进入详情的按钮、键盘及disabled语义。

- 若已有自定义用途，保留其实际名称的追加列和原详情入口；不删除、合并或改写该记录，不虚构自定义列。
