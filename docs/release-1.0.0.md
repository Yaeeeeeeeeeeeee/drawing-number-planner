# 图号规划器 v1.0.0

发布日期：2026-10-24。Windows 中文安装器支持自定义路径和桌面中文子文件夹；正式包无示例业务数据库和 PDF。

## 本次调整

- 图号库：版本列替换为字典颜色；主类别标签与项目单行；使用中/已停用双向切换，状态标签一致；源文件/转曲后文件按可靠实例展示，不把未命中当前批次等同于磁盘缺失，不随意选择多个候选。
- PDF：批次左键筛选、右键重命名/安全删除；保护 PDF、BOM、外发、人工归纳及产品归并历史。六项批量操作改名并在同一行左右分组，保持原有选择范围与索引保护。
- 共享表格：明显的表头拖动与列边调宽标记；新增缺失的恢复默认布局入口，保留本机布局设置。
- 安装：Windows Shell 文件夹选择器；选择桌面子目录时原样保留，桌面根目录进入独立的 DrawingNumberPlanner 文件夹。中文向导、静默安装和实际启动均属于发布验收范围。
- 仓库：精简 README 和当前 Skill，合并重复使用说明，移除已核实无依赖的旧设计草稿及过时阶段工作流；保留兼容迁移、安全保护和已验证回退版。

## 升级及恢复

先关闭旧程序，备份完整业务数据目录，再安装并继续选择原 planner.db。本版升级到 Schema20，只修正沿用图号状态更新触发器；保留编码、产品归属、历史占号、BOM、二维码、PDF 和外发历史。PDF 批次交互不需要新增表或数据迁移。

不清空数据库，不自动归并产品，不删除磁盘文件。归并和归属纠正仍由用户在本地核对执行。回退旧程序必须使用相应迁移前备份，不让 Schema19 程序直接打开 Schema20。详见 [安装与升级](install-and-upgrade.md)、[本轮修复说明](v41-v42-delivery-20261024.md) 和 Release 附带的实际运行报告。
