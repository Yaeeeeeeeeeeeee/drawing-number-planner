# 图号规划器 P4 · Windows 安装版

已确认的 P4 版本，应用修订为 `fc236a6`，已合并 master。本次只增加安装封装和固定下载入口，应用文件保持不变。

## 下载和使用

推荐下载 **DrawingNumberPlanner-P4-Windows-x64-Setup.exe**。在 Windows 10/11 64位系统双击安装，安装后从桌面“图号规划器 P4”启动。软件和运行文件一并安装，无需 Git、Node 或开发服务器。

需要免安装时，下载 **DrawingNumberPlanner-P4-Windows-x64.zip**，完整解压到新文件夹，双击其中的“图号规划器验收版.exe”。保留整个文件夹，不能只移动这个 EXE。

使用安装版或解压版任选一种；二者为同一应用版本。此包沿用此前交付的隔离样例，数据位于该版本独立的 AppData 目录，不自动读取或导入正式业务数据。安装与卸载均不清空该用户数据目录，不覆盖已有正式软件。不要把样例当作自己的正式资料。
