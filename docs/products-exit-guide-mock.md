## 只读核对

- ProductCleanupService.preview 返回 owned 各类所属数量、preservedSnapshots、classification 和 blockers 字符串。所属数量不是阻塞数量；没有图号状态拆分、阻塞记录 ID 或可定位跳转参数。
- cleanup 在事务中重新预检、精确型号确认、阻塞检查。图号删除为 retain_occupied；不释放号码。BOM 当前入口退出，二维码业务记录标记删除/停用，PDF 索引解除关联，批次归属待确认。历史身份、快照、草稿和磁盘文件保留。
- 图号库有作废及独立删除/释放预检；BOM 管理有查询编辑；二维码管理有独立受保护删除；PDF 文件中心只管理索引，不删除原始文件。全局清空资料库索引不作为产品退出前置步骤。
- AppShell 页面导航由本地 state 控制，产品 Mock 禁止导航到真实页面；没有可保留产品上下文并定位关联记录的可靠契约。本轮只提供经核对的文字处理路径，不虚构“前往处理”链接。
