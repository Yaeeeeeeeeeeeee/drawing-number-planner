# 图号规划器 v1.1.0

本版完成 V5 全系统增量修正：共用表格、包材 PDF 扫描与状态、BOM 编辑与图片、图号强制释放、外发文件与邮件模板。中文 Windows 安装向导支持自定义路径和桌面中文子文件夹；包内不含示例数据库。

## 主要变化

- 表头直接拖动换序、边界调宽和恢复布局；末列自适应，长表头冻结，常见字段统一对齐；页面标题和收起导航更紧凑。
- 包材只扫描产品目录下 `02.未转曲源文件`、`03.量产后的变更文件`。源文件独立归类；实际空批次可在核对磁盘和历史引用后清理失效索引。二维码手动 PDF 不受此目录限制。
- PDF、图号详情和外发共用实际文件状态。大 PDF 不再因旧 50MB 读取上限误报缺失；实际 ZIP 大小仍遵守原分包上限。
- BOM 增加类别联动、精简组合查询；编辑原值改按需只读抽屉；图片与位置示意图独立沿用/替换，支持统一放大、拖动和切换。所选记录在左，上一条在右；相同内容哈希不因路径或附件 ID 不同误报变化。
- 新增独立「强制取消占号并删除图号」，显示真实引用影响后确认。归档旧身份并保留 BOM/外发快照、审计和原文件；重新规划可生成新身份，旧同号 PDF 重扫不会自动串到新记录。正常取消占号仍保留原保护。
- 外发按品牌、真实类别和型号选择；简化重复控制，展示每份 ZIP 实际文件数。模板编码支持中文和连字符，厂家/场景可独立保存，字段错误与变量缺失明确，选定签名只追加一次。
- 修复外发同编码项不同类别被合并，以及 BOM 查询重置残留隐藏外观条件导致查不到记录的问题。

## 安装与升级

关闭旧程序并完整备份数据目录，然后运行本版安装器。首次启动继续选择原数据目录，不要创建空库替代原库。新版备份后事务升级至 Schema22；不自动归并产品、清空记录或释放号码。回退到 v1.0.0 必须配套使用升级前 Schema20 备份。

详见 [安装、升级及恢复](install-and-upgrade.md)、[修改、根因及验收明细](v5-delivery-20261026.md)。

## 验收边界

用户正式数据库、T40 原件和物理 Windows DPI 未提供；使用隔离旧库和真实临时文件验证，不宣称已在用户正式库执行。不同字节但视觉相近的图片仍保留不确定，不自动认定相同。未提供厂家模板 Excel，历史正文不自动替换。真实归并及强制释放由用户本地按实际资料确认。
