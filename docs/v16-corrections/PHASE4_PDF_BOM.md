# 阶段4：PDF中心与BOM

依据任务书 PDF-SCAN/PROGRESS/LIST/VIEW/META-001、BOM-EDIT/CREATE/QUERY-001。记录日期2026-11-17；仅隔离测试资料，尚不是Windows或用户正式库验收。

## 变更与保留

- `FileService`、`TaskRegistry`、扫描路由和 `useScanProgress`：全库、型号、类别扫描接入同一真实任务进度。目录遍历总数未知时不显示百分比；读取、索引比较、写入使用实际阶段。原有完整扫描失败保护继续生效；未覆盖目录不作缺失判定。不能可靠计算的跳过/访问失败文件数显示未知，不编造0。
- 原有500条上限分批管理已存在，复用 `pdf-batches.ts` 和 `PdfBulkManagementDialog`，没有另建扫描占号或索引系统。分批管理与扫描处理是两个不同流程。
- `FilesPage.tsx`、`pdf-list-groups.ts`、`v4-files.css`：右侧即时筛选、已选管理工具栏、查看勾选、切换筛选/导航清选；按产品、图号、转曲类型折叠已加载版本，折叠保留勾选。分组计数仅覆盖已加载数据，搜索不会伪造未返回的其他版本。
- 新 `PdfReader.tsx/css`、只读内容路由与默认程序IPC：完整阅读工作区、页码/缩放/适宽/旋转/缩略图/文本查找/全屏/打印及元数据。PDF.js资源同时配置开发和构建输出。行选择、文件名详情、双击阅读器、复选框操作分开处理。
- `BomQuery.tsx`：在型号前显示已有产品档案类别，不增加下拉筛选；`useTableLayout.ts` 对旧布局补入新列时保持既有相对顺序与宽度。
- `image-pixels.ts`、`bom-history-diff.ts`、`BomHistoryComparison.tsx`：对编码不同的图片解码后逐RGBA像素比较，尺寸或任意通道不同才算变化。不能解码显示待确认，可重试。比较请求与准确资产身份绑定，切换记录时取消旧请求；不重写历史附件摘要或原图。
- BOM按精确ID重开、保存后使用持久化附件ID、成功新增重置表单等既有逻辑与测试复用，未重建BOM录入或历史管理。
