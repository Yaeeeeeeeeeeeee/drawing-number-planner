# UI 一致性修正版（2026-10-23）

本轮依据用户批准的五步方案，使用 ui-ux-pro-max、frontend-design 与 impeccable 原始规范实施。保留黑白灰工程工具风格、四个详情分区与原有业务操作。

## 已实现

- 普通输入框、下拉框和主/次按钮统一36px；批量工具栏及文件行使用30px紧凑规格，图标/文本/复选框另保留各自适合的尺寸。
- 导航隐藏规则不再被display样式覆盖，通用空态与二维码复制统一Lucide。
- 图号详情不重复显示与图号相同的名称；清理旧V1和P4抽屉覆盖规则，四个分区内部透明，文件卡52px单行，危险动作与普通操作分隔。
- PDF只呈现一个空列表区域；批量栏使用中性色；按实际内容重新预算列宽，最小宽度由1260降为1080px，保留必要横向滚动与固定操作列。
- 二维码手动关联弹窗与现有抽屉共享焦点管理：初始焦点、Tab循环、Escape、背景inert和关闭后恢复；文件选择/保存处理中不能用Escape取消，取消不保存。
- 增补可复跑的真实页面检查脚本及Windows安装版布局/键盘检查。

没有调整Schema、占号资格、图号归属、产品换代、BOM或外发历史规则。没有操作用户本地数据库、原始PDF或执行ZC100归并。

## 本地安装

1. 关闭旧版程序，备份原数据目录及数据库。
2. 运行最终交付的中文安装程序，选择安装路径；如旧目录含早期示例版文件，选择新程序目录，不清理用户数据目录。
3. 首次启动选择原业务数据库；不要以创建空库替代升级。
4. 本轮无新迁移版本；程序仍支持旧Schema的备份后升级，不自动归并产品或释放号码。
5. 实际ZC100归并、纠正产品归属等业务操作仍由用户在本地明确执行。
