# V3 共享组件与交付整合

## 代码

- 三个指定列表复用 DataTable 的 `virtualize`；PDF 加 `onEndReached`、`virtualKey` 做100条增量读取。其它表格与图号分页不变。
- 虚拟DOM采用测量高度、前后占位行与有限overscan；主行和详情高度分开缓存，屏幕外关闭详情不会保留多余高度。查询键改变回顶部，展开/选择仍由各页面持有。
- QueryCache为160项LRU，过期时清扫，保留请求去重、失效后旧响应不能回填和变更通知。
- 产品查询加载期间保留同一表格；QR查询键切换复位；图号详情布局默认640、最大680。
- 三组九入口使用不同Lucide图标，18px/1.8；共享12px表格内边距、单行按钮、统一操作组。
- Schema18更新原生旧库升级辅助器与打包版本元数据；Windows真实手工QR使用新Warranty记录，保留原UserManual7，实际小写用途/空格/括号PDF验证。
