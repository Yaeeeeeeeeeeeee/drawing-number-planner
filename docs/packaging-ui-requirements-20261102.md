# 图号规划器｜包材模板、制图任务及图号规划 UI 优化需求

**项目：** `Yaeeeeeeeeeeeee/drawing-number-planner`

## 一、本次修改目标

当前图号规划器已经实现 AIT 模板管理、尺寸配置、图号规划、制图任务和 PDF 生成等相关功能。

经过实际测试，核心生成流程暂时没有发现明显问题，但功能入口、页面结构、配置方式、任务展示和交互设计存在较多不合理之处。

本次主要进行：

1. 重新划分「包材模板」与「制图任务」的页面职责。
2. 简化 AIT 模板字段映射、尺寸配置和模板匹配设置。
3. 简化图号规划页面，移除不必要的制图参数。
4. 优化图号实时预览及占号成功提示。
5. 优化制图任务创建、继续任务、任务详情及历史记录。
6. 调整临时文件的保存方式，取消任务子文件夹。
7. 衔接 PDF 文件中心的指定型号扫描、增量扫描和筛选功能。
8. 统一各页面的 UI 风格及响应式布局。

**本次以优化现有实现为主，不重新开发已经正常运行的 AIT 生成 PDF 功能。**

## 二、执行原则

1. 先检查当前代码、数据库模型和已实现的业务逻辑，再实施修改。
2. 不修改现有图号编码、查重、占号、历史 BOM 和外发资料规则。
3. 保留目前正在使用的 Windows 本地路径，不切换到服务器共享路径。
4. 不重新创建已有的模板、任务、图号或文件索引数据。
5. 界面改动不得造成历史任务记录丢失。
6. 不允许直接删除或覆盖原始 AIT、正式 PDF 及其他无关文件。
7. 保留现有可编辑 PDF 的生成能力。
8. 不额外生成独立 `.ai` 文件。
9. 不引入模板版本管理。
10. 修改完成后必须实际检查 UI 布局和交互，不以编译通过作为唯一验收标准。

## 三、左侧菜单及模块拆分

### 3.1 菜单结构

调整为：

**日常工作**

- 图号规划 / 更新包材
- 制图任务
- BOM 管理
- 外发资料

**产品明细**

- 产品档案
- 图号库
- 二维码管理

**数据来源**

- PDF 文件中心
- 包材模板
- 编码字典
- 迁移检查

其中：

- 「制图任务」紧跟「图号规划 / 更新包材」下面。
- 「包材模板」紧跟「PDF 文件中心」下面。

### 3.2 包材模板模块职责

「包材模板」只负责基础配置，包括：

- AIT 模板管理。
- 模板适用尺寸与匹配规则。
- 图号字段映射。
- 项目生成方式。

以下内容不再放在「包材模板」页面：

- 制图任务创建。
- 制图任务详情。
- 任务记录与历史。
- 任务刷新。
- 批量创建临时文件夹。

### 3.3 制图任务模块职责

将现有制图任务相关功能迁移到独立模块，包括：

- 从已占号项目创建任务。
- 继续未完成任务。
- 生成 PDF。
- 人工提供文件识别。
- 文件检查。
- 统一归档。
- 历史任务查看。
- 临时文件夹管理。

迁移页面时应复用已有任务数据及接口，不得创建第二套独立任务系统。

## 四、包材模板页面简化

### 4.1 页面总体布局

保留清晰的模板管理入口和筛选区域，取消重复功能入口及冗余说明。

建议将主要内容组织为：

1. AIT 模板管理。
2. 模板匹配规则。
3. 项目生成设置。

不再保留复杂、独立的「尺寸档案」维护表单作为日常必经流程。

页面应采用紧凑表格和必要的编辑表单，避免多个巨大配置面板同时展开。

### 4.2 AIT 模板管理

保留现有：

- AIT 上传。
- 模板名称。
- 项目明细。
- 适用产品型号。
- 启用状态。
- 原始文件管理。
- 模板匹配关联。

允许同一个模板适用于多个型号，同一个项目可以拥有多个不同尺寸的 AIT。

不需要模板版本管理。

### 4.3 AIT 只负责替换图号

用户已明确：

**所有不同尺寸的包材都有对应的 AIT 模板，系统不需要修改模板尺寸或其他设计内容。**

自动生成时：

1. 根据项目和本次尺寸匹配正确的 AIT。
2. 使用原始 AIT 的副本。
3. 找到图号文字对象。
4. 替换为本次已确认的完整图号。
5. 其他内容保持原样。
6. 导出保留 Illustrator 编辑能力的 PDF。

不要自动改变：

- 模板画板尺寸。
- 刀模尺寸。
- 图形尺寸。
- 排版。
- 品牌文字。
- 型号文字。
- 颜色内容。
- 其他未要求替换的对象。

目前只要求自动替换图号，后续如有其他字段需求再单独扩展。

### 4.4 字段映射界面优化

目前界面要求用户手动输入：

- 对象名称。
- 数据字段。
- 必填。
- PostScript 字体名称。

这种设计不够直观。

建议优化为：

**AIT 对象名称**

优先尝试自动读取 AIT 中可识别的文字对象名称，供用户选择。

**填入内容**

使用中文下拉选项，例如：

- 完整图号。

底层仍可使用 `DRAWING_NO` 等内部数据键，但无需用户手动输入。

**必填**

保留勾选功能。

**所需字体**

尽量自动检测；无法自动检测时提供手动填写方式。

如果自动读取对象名称或字体信息存在 Illustrator 接口限制，应保留可靠的手动设置途径，不得为了简化 UI 破坏现有生成能力。

### 4.5 项目生成配置简化

取消当前日常界面中的技术字段配置：

- 参数键。
- 显示名称。
- 类型。
- 单位。
- 尺寸轴。
- 手动增加多个参数行。

改为用户容易理解的配置方式。

首先选择项目及制作方式：

- AIT 自动生成。
- 人工提供 PDF。
- 无需生成文件。

如果选择 AIT 自动生成，再选择模板匹配依据：

- 无需尺寸。
- 二维尺寸：长、宽。
- 三维尺寸：长、宽、高。

内部参数名称和维度映射由系统自动处理。

已有参数数据应兼容迁移，不得直接删除或破坏现有模板匹配规则。

### 4.6 尺寸配置简化

取消原来复杂的「新增尺寸档案」界面中不必要的内容：

- 大量产品型号复选框。
- 为每个产品维护默认规格的强制流程。
- 锁定两个尺寸参数的比例。
- 比例参数 1 / 参数 2。
- 复杂的默认尺寸关联操作。

尺寸的主要用途是**寻找适用的 AIT 模板**，不是计算或改变设计稿尺寸。

模板匹配规则直接关联对应 AIT，支持：

- 长、宽、高的最小和最大范围。
- 小于、小于等于、大于、大于等于等条件。
- 长宽互换。
- 高度不参与互换。
- 无需尺寸的固定模板。
- 多个适用模板时由用户选择。
- 没有适用模板时明确提示。

如果已有通用规格或指定型号规格数据，可保留底层兼容能力，但不要求用户通过复杂档案表单完成日常制图。

### 4.7 包材模板页面 UI

- 表单标签位于控件上方。
- 同一行字段保持统一高度。
- 使用适中的输入框、间距和圆角。
- 减少不必要的浅灰色大背景面板。
- 删除重复小字说明。
- 配置表单不要占据整页大量空白。
- 保存操作放在对应配置区域的底部，位置统一。
- 页面窗口缩放时保持字段对齐。

## 五、图号规划页面简化

### 5.1 保留原有图号规划功能

图号规划页面继续负责：

- 产品类别。
- 产品型号。
- 外观。
- 主类别。
- 项目明细。
- 颜色。
- 备注。
- 图号实时预览。
- 查重并预览。
- 确认批量占号。

不改变原有图号规划规则。

### 5.2 删除本次尺寸配置大面板

当前每个规划项目下面出现的：

「本次尺寸 · 人工提供文件」

区域需要移除。

包括：

- 尺寸规格下拉框。
- 本次临时参数。
- 将本次尺寸另存为规格。
- 新规格名称。
- 设为此产品默认。
- 另存尺寸规格。
- 对应的解释文字。

**本次尺寸及模板匹配应在独立的「制图任务」模块完成。**

图号规划阶段不应要求用户维护 AIT 制作参数。

### 5.3 生成文件按钮

保留「生成文件」入口，位于「查重并预览」按钮左侧。

排列顺序：

**生成文件 → 查重并预览 → 确认批量占号**

功能要求：

- 已确认占号的项目可直接进入制图任务。
- 自动带入当前产品和已确认的图号。
- 不要求重新选择同一批图号。
- 未确认图号时，不得绕过查重与占号直接生成正式编号文件。
- 按钮可以作为进入制图任务的入口，实际 PDF 制作由制图任务模块负责。

### 5.4 图号实时预览调整

当前每个规划项目右侧都有一块面积很大的浅灰色实时预览区。

取消这种大面积左右分栏设计。

改为在每个项目字段下方展示紧凑的图号预览栏。

保留：

- 预计完整图号。
- 推荐流水号。
- 可占用或已占用状态。
- 必要的冲突提示。

每个项目单独显示预览，不能互相影响。

不得删除实时查重与预览能力，只调整呈现方式。

### 5.5 占号成功提示重新设计

当前成功提示为横跨页面的大面积浅绿色背景，信息层级不清晰。

改为紧凑的结果卡片：

- 左侧绿色勾选图标。
- 「成功占用 X 个图号」标题。
- 完整图号突出显示。
- 显示对应品牌、型号、颜色、项目明细。
- 每条图号提供复制操作。
- 「查看图号库」放在结果卡片右上方。
- 点击后直接定位到对应图号，而不是只进入图号库首页。

批量占号时，在同一区域列出多个结果，不生成多个巨大提示框。

成功信息不能因为无关的组件刷新而意外消失。

## 六、制图任务创建页面优化

### 6.1 页面标题和任务命名

当前出现类似：

「售后卡 · T40」

但实际任务可能包含铭牌、电池铭牌等多个项目，不能用其中某一个项目代表整批任务。

建议：

- 页面标题显示「SAMKYO · T40」等品牌和型号信息。
- 任务名称由系统自动生成。
- 不要求用户填写「售后卡」之类的任务名称。
- 内部 UUID 不出现在普通页面标题中。
- 任务实际包含的项目在下面单独显示。

内部仍可保留任务 ID 作为数据库关联依据。

### 6.2 简化任务创建表单

原有表单包含：

- 任务产品。
- 任务名称。
- 任务类型。
- 实际产品目录。
- 已保存图号选择。

建议日常创建流程改为：

1. 选择产品型号。
2. 选择需要制作的已占号图号。
3. 创建或继续任务。

任务类型如果确有业务用途，可保留必要的「新建文件 / 修改正式文件」区分，但不要要求用户填写无意义的名称。

实际产品目录应从产品档案的现有路径自动取得。

除路径异常或存在多个合法候选目录外，不要求用户每次手动选择目录。

### 6.3 一个型号一个未完成任务

沿用已确定规则：

- 同一产品型号同时只允许一个未完成制图任务。
- 不同型号可以同时存在各自的未完成任务。
- 任务完成后可以创建新任务。
- 任务中断后可以继续原任务。

不允许因为用户重复点击而创建多条未完成任务。

### 6.4 已有任务提示重新设计

当前提示：

「此产品已有未完成任务：售后卡 - UUID」

占据整条浅黄色区域，不够直观。

改为紧凑提示：

**T40 已有未完成制图任务**

显示当前任务状态和「继续任务」按钮。

要求：

- 不显示完整 UUID。
- 不重复显示已经选择的产品信息。
- 点击继续任务直接进入已有任务详情。
- 不重新创建任务或文件夹。
- 不重复占号。
- 已完成任务不阻止新任务创建。

### 6.5 临时文件夹创建

不要在任务创建区域长期显示独立的「创建临时文件夹」按钮及说明。

创建任务时自动检查：

`产品实际目录/00.临时文件`

如果不存在，则自动创建。

已经存在时直接使用，不重复创建、不改变原有内容。

批量创建临时文件夹的管理功能可以放到制图任务模块的辅助操作中，不占用日常任务创建主界面。

## 七、取消临时任务子文件夹

### 7.1 目录调整

取消原来的：

`00.临时文件/当前任务_UUID_任务名称/`

结构。

改为：

```text
产品型号
├── 00.临时文件
│   ├── 图号-铭牌.pdf
│   ├── 图号-电池铭牌.pdf
│   └── 图号-其他项目.pdf
├── 02.未转曲源文件
└── 03.量产后的变更文件
```

要求：

- 自动生成 PDF 直接保存到 `00.临时文件`。
- 人工提供 PDF 也直接放入 `00.临时文件`。
- 不自动创建带 UUID 的任务子文件夹。
- 系统通过产品、图号和任务记录确定文件归属。
- 不依赖子文件夹名称识别任务。

### 7.2 已存在任务目录的兼容处理

现有版本已经创建过：

`当前任务_48a153d8-..._售后卡`

等子文件夹。

修改后必须兼容这些历史数据和文件。

如果旧任务仍未完成：

- 检查原任务目录和实际文件。
- 安全处理原路径关联。
- 确认无重名冲突后再处理文件位置。
- 不得直接删除旧任务子文件夹。
- 不得因为路径变化造成任务文件丢失。

已完成任务的历史记录也必须继续可以查看。

### 7.3 归档成功后清理

归档成功后：

1. 确认所有本次任务文件均已正确归档。
2. 验证目标文件完整性。
3. 更新对应 PDF 索引。
4. 只清理本次任务实际使用的临时文件。
5. 不删除 `00.临时文件` 文件夹。
6. 不删除其他无关文件。
7. 保留任务历史。

归档失败或文件仍有冲突时，不清理临时文件。

## 八、制图任务详情页面优化

### 8.1 顶部信息

当前任务详情顶部显示：

- 带单个项目名称的任务标题。
- UUID。
- 原始完整任务路径。
- 多个刷新状态文字。

建议改成：

**SAMKYO · T40**

下方展示：

- 当前任务状态。
- 本次文件数量。
- 已完成数量。
- 待处理数量。

内部 UUID 和完整路径可在需要时查看，不作为主要信息长期展示。

### 8.2 项目列表紧凑化

当前每个项目都使用面积很大的浅灰色卡片，包含完整宽度的生成方式下拉框、说明及保存按钮。

建议改成紧凑的项目列表或适度高度的项目行。

主要字段：

- 完整图号。
- 项目明细。
- 颜色。
- 文件制作方式。
- 模板匹配结果。
- 文件状态。
- 操作。

必要时展开单个项目的详细设置。

不要让每个文件都占据页面数百像素高度。

### 8.3 制作方式

每个项目允许：

- AIT 自动生成。
- 人工提供 PDF。
- 无需生成。

选择 AIT 时：

- 按项目要求显示本次尺寸。
- 自动匹配 AIT。
- 必要时人工选择匹配模板。
- 仅替换图号。
- 生成可编辑 PDF。

选择人工提供时：

- 不显示不必要的尺寸参数。
- 系统监听 `00.临时文件`。
- 根据完整图号优先识别 PDF。
- 无法唯一匹配时允许人工关联。

### 8.4 批量生成

保留：

- 批量生成待处理项目。
- 单项生成。
- 单项失败重试。
- 单项跳过或无需生成。
- 任务状态刷新。

一个文件生成失败不影响其他项目。

已经人工修改的文件不得被重新生成操作直接覆盖。

### 8.5 统一归档

保留按任务统一归档的规则。

归档前展示文件清单和检查结果。

全部需要归档的项目准备完成后，由用户统一确认。

成功后更新正式 PDF 索引并清理相应临时文件。

## 九、制图任务历史记录优化

### 9.1 增加删除功能

在「任务记录与历史」表格的操作列中，增加「删除」按钮。

操作列包含：

- 查看记录。
- 删除。

删除按钮采用明确但克制的危险操作样式。

### 9.2 删除规则

**已完成任务**

允许删除历史任务记录。

**未完成任务**

不能在用户不知情的情况下直接删除，应提示其处于未完成状态，并明确处理后果。

要求：

- 删除前进行二次确认。
- 显示对应产品、任务状态和创建时间。
- 不删除实际 PDF。
- 不删除原始 AIT。
- 不删除正式文件。
- 不释放已占用图号。
- 不修改 BOM 或外发历史。
- 不清理无关 PDF 索引。

如未完成任务删除涉及当前任务锁定及临时文件关联，必须先检查并安全解除对应关联，不得留下无法继续、也无法创建新任务的异常状态。

### 9.3 历史表格显示

- 隐藏任务名称下方的 UUID。
- 时间格式使用本地可读格式。
- 例如 `2026-11-02 11:34`。
- 不显示 `2026-11-02T03:34:53.572Z` 这种原始时间字符串。
- 产品型号、任务类型、状态、时间及操作列对齐。
- 删除成功后立即更新列表。
- 保留原有排序、列宽调整和恢复默认布局能力。

## 十、PDF 文件中心筛选与扫描

### 10.1 保留现有本地扫描路径

继续使用目前实际配置的本地产品资料目录。

不切换到此前讨论的服务器共享路径。

### 10.2 文件扫描范围

正式 PDF 扫描只处理每个型号下：

- `02.未转曲源文件`
- `03.量产后的变更文件（已量产的产品看最新日期）`

`00.临时文件` 不参与正式图号库 PDF 索引。

其他目录里的无关 PDF 不参与正式图号匹配。

### 10.3 指定型号扫描

PDF 文件中心左侧产品目录支持：

- 全部产品。
- 产品类别。
- 产品型号。
- 搜索产品型号。

选择某个型号执行扫描时，只扫描该型号的规定目录。

不得每次修改一个型号就重新扫描整个产品盘。

### 10.4 扫描方式

保留并完善：

- 自动文件监听。
- 增量扫描。
- 指定型号扫描。
- 手动全量扫描。
- 启动后的补充检查。

自动监听发现变化后，只对相关型号进行增量检查，不反复扫描全部产品。

### 10.5 文件列表筛选

保留以下快捷筛选：

- 全部文件。
- 源文件。
- 转曲文件。
- 缺失文件。

保留详细筛选：

- 文件类型。
- 文件批次。
- 文件状态。
- 变更日期范围。

特别要求：

**左侧产品目录决定扫描范围，右侧详细筛选主要决定列表展示范围。**

不能因为只显示某个批次，就漏掉其他历史批次的正式文件索引。

### 10.6 扫描结果和安全

扫描后展示：

- 扫描文件数量。
- 新增文件数量。
- 更新文件数量。
- 已确认缺失数量。
- 扫描失败数量。
- 未匹配图号数量。

扫描失败、目录无法访问、文件正在写入或扫描未完整覆盖时，不得直接判定相关文件缺失，也不得批量清空索引。

## 十一、统一 UI 设计要求

本次不仅需要功能调整，还需要整体视觉优化。

### 11.1 设计方向

目标是：

**简洁、紧凑、层级清晰、易于操作的 Windows 桌面业务管理工具。**

参考此前讨论中已确认的聊天界面示意风格，但需要与现有软件整体风格保持一致。

### 11.2 统一组件

要求统一：

- 页面标题。
- 分区标题。
- 表单标签。
- 输入框高度。
- 下拉框样式。
- 按钮高度。
- 圆角。
- 边框。
- 表格行高。
- 空状态提示。
- 成功及错误提示。
- 操作区域对齐方式。

### 11.3 避免的问题

不得出现：

- 功能区域整页铺满浅灰色背景。
- 一两行内容占据巨大卡片。
- 多个字段因空间过大而分散。
- 大面积无意义留白。
- UUID 和内部技术字段直接展示给用户。
- 冗长重复的解释文字。
- 操作按钮与所属内容距离过远。
- 不同页面的控件尺寸明显不一致。
- 页面缩放后布局错位。
- 局部组件抽动或重复刷新。

### 11.4 表单与表格

- 标签优先放在输入框上方。
- 同行字段保持对齐。
- 长文本字段与短字段分配合理宽度。
- 表格占满可用区域。
- 表头与单元格对齐。
- 不因列宽变化出现右侧大块空白。
- 保留有效的列拖动与列宽调整功能。
- 不再额外显示无用的拖动提示和技术说明。

### 11.5 页面不要重复配置

同一业务配置尽量集中在一个位置。

例如：

- AIT 原始模板、匹配规则放在包材模板。
- 本次尺寸、模板选择、文件生成放在制图任务。
- 图号查重和占号放在图号规划。
- PDF 索引和扫描放在 PDF 文件中心。

不要让用户在多个页面重复填写相同的数据。
