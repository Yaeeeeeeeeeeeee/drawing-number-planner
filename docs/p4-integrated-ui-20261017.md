# P4 图号库与外发配置整合候选

本轮基于 e9368c3，保留此前产品档案八列/用途导航、BOM原记录编辑与无复制控件成果。用户已明确授权完成本轮后直接交付Windows验收包，替代此前暂停打包要求。不合并master，不修改Schema、用户真实数据库或磁盘原文件。

## 图号库

产品/批次树从产品档案及现有资料批次读取。新增只读 productId、usageBatchId、associationState 查询参数；原 materialBatchId 仍保持PDF出现批次含义，避免兼容调用改变语义。实际使用关系仅取未删除BOM条目/版本及已完成外发包条目的明确图号身份。BOM当前状态以精确 bom_current 产品/版本指针判断；外发使用 selected_material_batch_id，source_material_batch_id 仅是文件来源，不用于实际使用筛选。不凭日期最新、PDF扫描或图号文本相同推断关系。

身份始终为 origin + ID；同一图号跨批次不重复计为占号，已释放图号重新使用时不转移旧身份关系。产品范围包含该产品自身图号及明确使用的共享图号；批次范围只取实际使用，不补造缺失关联。历史同码身份在对应范围仍可读取。数据缺失保留未确定状态。

独立版本字段当前未记录，列表显示“未记录”，不将图号末三位序号伪作版本。PDF出现位置与实际业务批次关系分开展示。详情默认查看、关联批次和历史文件折叠；维护操作集中同抽屉管理模式。PDF关联先暂存，保存才调用原接口；取消不写入。分步保存失败诚实提示已成功部分，重试仅失败部分，既有危险操作仍独立确认。

## 外发资料

保留现有选择、核对、生成结果及邮件草稿流程。邮件配置单独入口，模板/签名/联系人互斥标签，每次一个编辑表单，默认紧凑列表。未保存确认覆盖换模块、换编辑对象、取消、返回工作台、主导航离开和关闭窗口；保存中阻止离开与重复提交。删除当前编辑实体或父模板后清理对应编辑器。

工作台隐藏保留邮件草稿；返回配置后重新加载实际可用联系人、模板、签名及段落，不重建组件、不静默覆盖人工正文。CRUD、引用检查、停启用和删除能力继续调用原API，无新字段或迁移。

## 验证与交付

此文先记录实现方案，测试和截图结果在执行后补充。环境曾两次重建丢失未提交文件，本轮按各任务命令重建实现，测试必须重新执行，旧结果不能当作当前通过。采用阶段性远端检查点，测试串行限worker，避免资源争用。

Windows目录包复用原已交付P4隔离样例和运行时；不新增记录制造密度。样例只有一版BOM，不能证明真实多版本差异全部验收。原生CI窗口内容尺寸与物理Windows4K最大化、系统DPI、跨屏和用户真实业务数据验收分别记录。


## 人工验收步骤

1. 完整解压最终验收包到新目录，双击 EXE，标题核对应用短版本。不覆盖旧版；包内独立数据供本轮验收。
2. BOM 查询记录原总数/业务日期/原始提交时间，修改一个材质字段保存，确认总数不增加、原身份/日期不变，批次不铺开路径，详情无二维码关联及复制按钮。
3. 产品档案核对固定八列，三种资料状态分别跳转对应产品/用途；多条匹配列出全部，未配置入口不自动创建。返回核对筛选与资料状态刷新。
4. 图号库展开产品，点击当前/历史批次；核对列表是明确BOM/已完成外发使用关系而非所有扫描PDF。同码跨产品/批次使用不产生重复占号。没有明确关系的批次显示未确定，空列表不补造数据。
5. 打开图号详情：完整图号与复制同行；两列基础信息；源文件/转曲后各自判断；路径/历史文件/关联批次默认折叠。历史批次无文件时不能替换成当前文件。多产品共用时只显示所选上下文文件。
6. 管理图号中暂存PDF后取消，关联不变；保存、重复角色拒绝、部分失败后仅重试失败项。保存中切换导航/记录/关闭不能中断剩余保存。危险操作仅核对入口及保护，未经明确数据操作不要执行释放或删除。
7. 邮件配置逐一切换模板/签名/联系人，新建/编辑/取消/保存；输入后拒绝离开保留输入，确认放弃后切换。删除编辑对象后不得留下指向已删除ID的编辑器；成功保存后列表刷新失败不重复创建。
8. 返回工作台核对配置选择已刷新、手工正文保留。选择产品/批次、预览核对文件，按实际原流程生成包/邮件；此操作仅在明确隔离资料中验收，不选正式资料根目录。外发包/历史/命名和分包规则未调整。
9. 在实际Windows 1080P/2K/4K最大化、普通/窄窗口及系统DPI/跨屏检查：整页无横向溢出；表格内部可横滚且操作列可达；抽屉独立滚动；保持筛选和产品导航上下文。

原样例只有首次BOM记录，不能用于全部历史新增/删除/修改状态验收；原历史对照单元测试保留。真实多历史数据及物理Windows4K/DPI/跨屏仍需用户本机确认。

## 回归范围与审查

新增查询只读，不改原图号查重/占号/释放、二维码独立状态、BOM编辑及外发快照、PDF索引写入或磁盘原文件。独立审查发现的保存中导航锁、其他产品源文件归类、配置成功写入后刷新失败重复提交均已修正并增加回归；最终只读复查未发现这些修正中尚未处理的重要问题。

全量测试不能称为全绿：此前16个同名基线失败涵盖Windows路径/临时产物清理及暂停Mock；详见机器可读报告。实际Windows原生验收记录与云端CSS视口模拟分开，避免将CI显示器尺寸当成人工物理4K验收。
