# v1.6.2 · V1.6 本轮修正

本版基于用户已验收的 V1.6 和 1.6.1 启动修复，按原任务书44项增量实施，交用户重新进行完整验收。源码、测试及 Windows 原生运行的证据分别记录，不将自动化通过写成用户已经验收。

## 主要调整

- 复用任务安全结束、锁和删除预检保护；图号删除或PDF强制脱钩后可保留文件结束，不重新认领旧PDF，不伪装归档成功。
- 模块切换保留各自工作现场；AIT新增/编辑使用真正覆盖式右抽屉，保存成功清除未保存状态，失败保留输入。
- 四步规划工作台保留单型号/批量两模式及独立持久草稿；默认共用必须来自产品真实白色记录，非白色项目可选择独立占号，中文拆解及流水号含义明确。
- AIT直接引用用户选择的原始路径，可重新定位；尺寸完全相等优先，其他多匹配保持冲突。只替换完整图号文本，禁止新建时覆盖既有目标。现成/人工方式复用可靠文件；多正式候选优先唯一02源文件，否则待确认，强制脱钩文件不参与。
- PDF按02/03既有范围监听与扫描，型号/类别/全库进度使用真实阶段；失败或未完整覆盖不批量判缺失。即时筛选、选择及折叠保持，02与03不混组。新增只读PDF阅读器，支持分页、缩放、旋转、缩略图、文本搜索、全屏和打印调用。
- BOM增加类别展示并修复编辑/保存现场；图片按原尺寸解码RGBA逐像素比较，相同像素不因编码/路径不同误判变化，失败显示无法确认。
- QR保留独立模块和手动关联，新增默认停用；菜谱仅向空气炸锅开放。更换PDF只比较第一页像素，后续页不参与，结果仅供核对，不自动关联或去重。
- 字典项目搜索和父级停用校验一致；原Excel模板导入继续使用既有入口，不重复建立邮件系统。
- 单PDF超过50,000,000字节留在外发清单并提示独立传输，不进ZIP；最终ZIP不超过50,000,000字节。邮件提供明确保存和恢复草稿，保持准确包/产品/批次/文件上下文，不自动发送。
- 数据库重新选择只选一次文件，检查兼容性和完整性、确认摘要后切换；失败恢复旧配置和服务，不合并数据库。

## 数据与升级

Schema由25升级26，仅为既有制图项目和任务制作方式增加独立 `existing` 值；旧 `none` 记录继续保留。迁移先独立备份并验证，再在事务内保留所有旧表行、索引、触发器、序列和外键；逐行有界内存校验避免大库整体JSON序列化。数据库切换、QR像素比较、邮件草稿没有另建业务表。

本次开发未操作用户生产数据库、配置或真实PDF/AIT/AI/图片，未执行生产数据修复或归并。扫描根路径沿用用户现有本地配置，不改为网络共享。安装与卸载不会清除数据目录。

## 验证与限制

最终完整Vitest **241文件、2101项通过**，完整Chromium **26项通过**；最后目录分组补强再通过3文件51项和真实PDF浏览器1项，数量不与整套重复相加。类型检查、渲染器/Main/服务构建通过。Windows最终运行、安装器SHA256及截图以同页正式验证报告为准。

未提供授权Adobe及用户真实AIT，**真实字体、版式、对象保持和PDF重新打开编辑尚未验证**；协议/JSX和匿名AIT路径测试不能替代它。物理DPI、跨显示器、实际打印机以及用户原T40数据库也尚未验证。

模块现场保留主要在当前会话；跨进程恢复的是规划持久草稿和用户明确保存的邮件草稿，不能推断所有临时表单自动保存。全部文件均超50MB时只生成当前会话独立传输清单，不伪造ZIP或ZIP历史。PDF的CJK/CID/JPX真实业务样本尚未提供，内置所需资源不等于这些文件已验收。

完整逐项证据、实际修改文件和剩余事项见[需求矩阵](v16-corrections/REQUIREMENT_STATUS.md)、[修改清单](v16-corrections/CHANGED_FILES.md)及[交付记录](v16-corrections/CANDIDATE_DELIVERY.md)。

## 本地安装、首次启动与回退

1. 退出旧版，备份**实际正在使用**的完整数据目录（可从 `%APPDATA%\DrawingNumberPlanner\profile.json` 的 `dataDir` 核对）。保留数据库、存在的WAL/SHM、设置、备份及托管附件，原始资料另外保留；不要只按data/data-*名称或文件大小选择库。
2. 下载1.6.2安装器，对照 `SHA256SUMS.txt`。可选中文目录或桌面下的独立子目录；安装目录只放程序。
3. 安装后首启选“使用旧数据库”，选择你确认需要继续使用的原 `planner.db`。不要新建空库代替兼容升级。等待备份、迁移与健康检查完成，失败保留原目录并查看提示及日志。
4. 核对产品、BOM、QR、任务历史、资料根目录及外发路径，再按任务书重新验收。真实AIT先用一份模板核对字体、版式、完整图号和PDF重开编辑。
5. 如需回退1.6.1：退出1.6.2，完整保留升级后的目录，在独立目录恢复迁移前验证过的Schema25备份及附件，安装旧程序后明确选择恢复库。1.6.1不能直接打开Schema26；备份不含升级后的新增业务，不应覆盖唯一的新库。

软件不会自动安装到用户电脑，不会自动执行ZC100归并、强制释放图号或重认领脱钩PDF。
