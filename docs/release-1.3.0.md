# 图号规划器 v1.3.0 · V5.2 增量修正

- PDF 新扫描限定两个指定目录；源文件与全部有效生产批次分别识别。遍历失败不会提交不完整扫描，范围外旧索引保留；暂时无法访问与确实缺失分开处理，不删除原始资料。
- 图号详情取消批次下拉，按对应图号核实源文件及全部转曲后批次。未索引文件可只读核验，同批次内容冲突不任意选择；首次 BOM 跳转到原记录，不误跳到当前记录。
- BOM 可更正原记录业务日期，保留 ID、创建时间、上下游及快照；修复上一版同项目图片/示意图沿用，替换上传独立校验。查询保留三个下拉、增加项目明细，新建成功清空临时录入。
- 表格指定列居中，缩列空间交给最右侧列；保留换序、宽度记忆和重置。产品/二维码/PDF 操作区冻结，PDF 六个动作改为带中文提示的图标；修复尺寸测量、展开行观察和二维码切页/聚焦的重复工作。
- 修复真实 Excel 的供应商分组及场景识别：20 个首批场景、5 个更新案例独立保存，收抄送人和签名分开处理。原案例及单元格来源可追溯，历史原因/文件清单不直接固化为通用更新正文。重复导入先核对，防止覆盖手工修改。
- 切换厂家重置收抄送配置，防止旧厂家地址残留；同厂家内的手动调整与手工正文继续保留。

Schema23 仅补充既有邮件配置的联系人关系及来源历史；升级前备份、事务迁移并验证原字段和外键。保留历史图号占用、PDF 索引、二维码、BOM 和外发快照，不自动执行真实产品归并或号码释放。安装包不包含示例业务数据库、用户 Excel 或个人联系资料。

使用步骤：[安装、升级与恢复](install-and-upgrade.md)。验收记录：[V5.2 交付记录](v52-delivery-20261030.md)。用户本地实际数据库和物理 Windows DPI 仍需现场核对；自动化隔离数据验证与生产库验收分别记录。
