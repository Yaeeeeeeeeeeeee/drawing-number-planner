# v1.1.2 最终补充修复

本版包含 [v1.1.1 三项修复](hotfix-1.1.1-20261027.md)：已知括号生产目录扫描与源文件独立归类、容器内分配列宽、每次安装后选择旧库或独立新库。原库、PDF、占号及历史引用保护不变；沿用Schema22，无新增迁移。

实际Windows截图复核发现，v1.1.1已经正确识别源文件并显示在源文件导航下，但表格把“未转曲源文件”放进“批次状态”列，导致“资料批次”列仍显示“未归入批次”。这是展示字段错误，不是新的扫描或关联规则问题。

修正后：

- 资料批次：未转曲源文件。
- 批次状态：—，不显示当前/历史批次。
- 真实生产文件继续显示原批次及实际批次状态。

新增前端回归先复现“未归入批次”错误，再检查正确的两个单元格。Windows原样目录验收也新增对这两个单元格的真实检查。相关自动化、完整回归与Windows补充验收正在执行；发布后补充运行及摘要。

用户正式数据库和原PDF未在环境，验收使用原样目录/文件名的隔离真实文件。升级保留原数据请选择旧库，再执行一次扫描；创建新库不要求文件选择，且不覆盖旧库。
