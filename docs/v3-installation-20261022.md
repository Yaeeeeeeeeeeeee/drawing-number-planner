# V3 本地安装、升级与验收

此文件是操作说明；实际提交、测试、安装包与 Windows 验证结果以本轮最终交付记录为准。

1. 关闭旧程序，确认任务管理器没有仍在运行的图号规划器进程。保留原数据目录，其中包括 `planner.db`、`settings.json`、附件和既有备份；不要把原始PDF目录当作程序目录覆盖。
2. 解压本轮安装包ZIP，运行其中 `图号规划器-Windows-x64-安装包.exe`。向导为中文，可以自行修改安装位置。建议使用新的程序目录；含旧验收样例目录的目标会被拒绝，程序不会删除其中的内容。
3. 已保存稳定数据配置时，新版继续使用原来选择的数据库。首次出现选择窗口时，现有用户选择原 `planner.db`；只有确实希望创建新空库的用户才选择新建。
4. 旧库升级先创建可读取备份，再在事务中升级至Schema18。只调整既有绑定表的可空兼容约束，旧历史数据及引用继续保留。升级失败会中止并回滚，不会清库重建。
5. 核对产品、图号总数、占号状态、PDF批次、QR文件关联、BOM和外发历史。新版不在启动时自动执行产品归并、历史关联写入、索引清理或号码释放。
6. 图号库进入关联诊断，先查看真实总数、有效关联、候选与冲突原因；已有可靠关系直接通过查询体现。需要人工补齐的记录，核对产品与依据后确认；程序保留备份与审计，歧义不会按前缀强制归属。
7. PDF待关联入口与全部文件互相切换，核对筛选结果/数量。批次同名可能来自不同路径和ID，应在明细核查，不能只凭名称合并。改名只改显示名。
8. QR可直接手动关联真实命名PDF，例如 `B500-warranty（hwh0kd9）.pdf`。用途大小写和括号附近空格兼容；型号、实际PDF格式与目标网址七位尾码仍必须正确。原文件不会重命名、移动或删除。
9. 外发预览选择品牌、产品、资料批次、资料类型、范围。完整资料只取选定批次转曲PDF；本次变更按可靠前一批比较，不能确定基准时人工选择，不静默混入其他外观码资料。

回退：关闭所有新版进程，保留当前库副本和升级前 `backups/migration-*.db`。将选中的升级前备份复制到独立恢复目录，配套保留原 `settings.json` 和附件路径，再使用原软件版本明确选择该恢复库。不要让旧程序直接打开Schema18库，不覆盖唯一数据库或删除其WAL文件；如出现锁定先确认进程已退出。

需要本地人工验收：真实758条历史数据的诊断与必要确认、同名批次来源判断、实际业务文件选择、物理4K/缩放/跨屏/输入法。开发环境只有隔离夹具，不能声称真实758条已全部关联。独立外观版本日常入口已按V3取消；不执行此前方案中的ZC100自动归并或启用操作。
