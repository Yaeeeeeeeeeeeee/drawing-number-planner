# 图号规划器 1.6.2 · 第一批 P0 Windows 验收版

应用版本 **1.6.2**，数据库 **Schema26**。验收包使用固定源码 `ca5d58a430983b9875fe7ac46152f65561e9bdad`。

- PDF 扫描先登记任务和互斥所有者，再检查目录。取消和服务重启等待 I/O 收尾或旧服务退出，保留最近成功索引。
- 新占号图号显示黄色「待启动」，保留原有占号及显式启停规则。
- 成功 scanId 触发 PDF 文件中心和图号库刷新，包括 ZC 匹配及归类候选。正式归属仍由用户操作，保留人工绑定、强制脱钩和审计记录。
- 强制脱钩 PDF 在重启补扫后继续保留强制脱钩诊断标记，PDF 索引、文件内容及原有隔离关系保留。

沿用项目原有 Windows 工作流及 Inno Setup 安装器。此包供 P0 现场验收使用，保留现有正式版下载。用户本机、真实 SMB/NAS 和生产 ZC 档案 ID 按现场清单验证。
