# 图号规划器 v1.6.0

在 v1.5.0 / Schema25 上增量修复，保持原 Windows 本地运行和资料根目录配置。本轮不新增数据库 Schema。

- 制图任务增加「保留文件并结束任务」，图号删除、PDF强制脱钩或索引中断不再要求先重新关联旧PDF才能结束。实际文件操作未结束时保留任务锁；结束留痕，与归档成功区分。删除预检失效可在原弹窗重新核查。
- 图号规划采用产品资料、选择项目、图号检查、确认占号四步。单型号和多型号批量模式独立，按型号保存项目、分组查重、单项重查和明确确认；成功结果按实际ID进入图号库及制图任务。
- 颜色共用只引用同产品真实存在的白色记录，不伪造白色、不跨型号共享、不改变既有图号或BOM。不同项目/型号出现相同完整图号会作为编码冲突阻止，不引入新流水规则。
- 两种草稿分别持久化在当前数据目录的 planning-drafts.json，原子保存和版本冲突保护，重启恢复后必须重新检查。每日数据库备份创建时一并保存有效草稿副本；删除草稿不释放占号。
- 返回制图任务时刷新任务历史和当前详情，保留筛选、展开及未保存设置，防止旧请求覆盖新数据。模板、任务、PDF及二维码辅助资料明确显示加载、空结果、失败和重试。
- 所有启用产品的02/03目录参与监听，不依赖00目录或未完成任务。增加当前类别扫描，保留当前型号和全库扫描；共享目录仍按完整历史归属检查拒绝。
- PDF列表显示上次扫描状态，展开文件路径时单独实时核实，不因列表筛选逐行访问磁盘。批量操作超过500条自动分批，显示进度、逐批结果并保留失败重试，已成功批次不重复提交。
- 安全恢复及原生菜单增加重新选择数据库。已有库先检查版本、结构、完整性和外键；独立验证备份、暂停操作、验证目标服务成功后才保存配置，失败保留原配置并恢复服务。不自动合并数据库。

## 数据和使用边界

不清空或重建生产数据库，不自动归并产品，不自动重新认领强制脱钩PDF，不因停用/结束任务释放占号，不删除原始PDF、AIT、AI、BOM附件或外发历史。本轮未连接用户本地正式数据库，测试使用隔离数据库与真实文件操作。

当前数据库已损坏或缺失、不能建立完整性验证通过的备份时，重选会明确拒绝；需先恢复可读取的数据库。原文件和配置保留。无授权Adobe Illustrator及用户真实AIT，本版不声称已验证实际字体、版式或可编辑PDF重开。

## 安装、升级和回退

关闭旧程序，将整个原数据目录另存备份，包含planner.db、WAL/SHM（如仍存在）、settings.json、附件、草稿和backups。下载本版正式Release中的安装器，核对SHA256后安装。每次重新安装首次启动仍选择旧库或新库；保留业务请选择原planner.db，资料根目录继续沿用原本地路径。

需要改用其他库时，在「安全恢复 → 重新选择数据库」明确选择已有planner.db或数据目录。取消不会更改配置。程序执行校验和备份，切换失败按提示重试；不要手动合并两个数据目录或在运行时替换数据库。

回退时关闭程序，保留本版数据及备份，使用此前保留的v1.5.0安装包和独立备份副本。不要覆盖唯一一份当前数据库，也不要通过删除PDF、索引或占号解决兼容问题。本轮Schema仍25；新草稿侧文件不会被旧版本使用。

正式源码、安装包、SHA256、Windows实际安装/升级截图与测试报告以对应Release附件和交付报告为准。本文功能说明不替代Windows运行验收。
