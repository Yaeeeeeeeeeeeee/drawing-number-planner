# 图号规划器 1.6.2 全范围验收版

本轮包含第一批 P0 和后续规划、制图任务、包材模板、PDF、图号库、二维码、BOM 及公共界面修正。完整源码提交为 `56fb2efc6c6d3313c6823fd6b8f210d309325506`，数据库沿用 Schema26。

- 在「批量规划」按产品线搜索并勾选型号。三个步骤依次选择产品与外观、配置项目、检查并确认占号。单型号「新建图号」保留四步。旧批量草稿恢复后重新查重，正式占号前仍需主动确认。
- 从包材模板导入主类别和项目明细，按选定目标型号复制项目。各型号的外观、颜色共用和占号分别校验。
- 制图任务列表收起辅助操作，详情区分来源、文件核验和索引进度。取消任务保留文件，原有删除资格检查继续生效。
- PDF 文件中心按当前范围检索、分组并展示路径操作。图号库支持表头选择和按需显示来源列。已选记录和全库归类动作标明范围。
- 二维码区分已配置和待关联用途。包材模板支持型号分组选择、保留手动映射和查看项目生成设置摘要。Illustrator 状态依实际探测结果显示。
- BOM 详情可复制图号、按需对比上一版，并导出所选记录的 A4 PDF。编辑时按项目和用途提供可沿用的图片；更换图片可单独操作。
- 旧版文件中心的上传和网格视图、迁移检查的文件管理器直接切换保留现场核验标记。真实 SMB/NAS 和实际 Illustrator 设计文件另需现场验证。

安装前退出旧版本，保存当前数据目录路径及其可读取的完整备份。使用原资料时选择已有数据库。回退可使用原安装包和原数据目录的独立备份。请保留验收期间新增的数据，再决定使用哪份副本。
